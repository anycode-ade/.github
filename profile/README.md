# anycode-ade

**Anycode is an ADE for humans and AI agents.**

Run it locally or remotely, open it from any device, and build with the agents you already use.

## What We Build

Anycode is a browser-based development environment that combines:

- a fast custom editor
- a Rust backend for filesystem, terminal, and LSP access
- flexible multi-pane workspace layout
- built-in git workflows
- ACP support for agent integrations

The goal is to make coding with agents feel natural, portable, and productive.

## Main Project

- [anycode](https://github.com/anycode-ade/anycode)  
  The core Anycode repository with the React frontend, Rust backend, terminal support, LSP integration, git tools, and AI agent workflows.

## Highlights

- Browser-based development environment
